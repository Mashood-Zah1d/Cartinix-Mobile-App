# Cartinix Mobile App

Full-stack mobile eCommerce application built with React Native, Node.js, Express.js, and MongoDB.

## Overview

Cartinix Mobile App is a mobile shopping application connected to a custom backend API. It provides an eCommerce experience for browsing products, managing a shopping cart, placing orders, and interacting with the application through a mobile interface.

## Features

* User registration and authentication
* Product browsing
* Shopping cart management
* Order placement
* Backend REST API integration
* MongoDB database
* AI-powered chatbot
* Text and voice interaction with the chatbot

## Tech Stack

### Mobile

* React Native
* Expo
* JavaScript

### Backend

* Node.js
* Express.js
* REST API

### Database

* MongoDB

### AI

* AI chatbot
* Text and voice interaction

## Project Structure

```text
Cartinix-Mobile-App/
├── Backend/
└── my-app/
```

* `Backend/` — Node.js and Express.js backend API
* `my-app/` — React Native mobile application

## Getting Started

### Backend

```bash
cd Backend
npm install
npm start
```

### Mobile App

```bash
cd my-app
npm install
npx expo start
```

## Environment Variables

Create a `.env` file in the backend and configure the required environment variables.

Do not commit sensitive credentials or API keys.
